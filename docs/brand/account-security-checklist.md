# S0｜账号与恢复安全检查单（仅模板，不存放秘密）

> 文件可用于个人离线追踪，但**不要**把填写了具体账号信息/恢复通道的版本推到公开仓库。

## GitHub

- [ ] 确认最终用于创建组织的 GitHub 账号
- [ ] 开启 2FA（优先通行密钥 / 身份验证器）
- [ ] 安全保管恢复码（放在密码管理器等安全位置，**不要提交到仓库**）
- [ ] 创建或核实组织的实际 handle
- [ ] 组织中增加第二名可信 Owner；如暂时无法达到，记录等效应急恢复流程
- [ ] 禁止公开存储访问令牌，检查成员最小权限
- [ ] 明确组织管理账单、成员邀请与安全设置的责任人

## 域名

- [ ] 用注册商实时确认域名及价格、续费成本、隐私保护、转移规则
- [ ] 确保域名由品牌实际持有者控制，不由临时外包账号持有
- [ ] 启用注册商多因素验证、自动续费提醒和安全恢复
- [ ] 将 DNS 托管与域名所有权信息记录在**非公开**安全台账

## S0 验收

- [ ] GitHub 组织管理权与恢复方式实际可用
- [ ] 核心域名归属与续费责任明确（如 S0 决定暂不购买，需明确记录并解除官网依赖）
- [ ] 对外账号/链接已替换为真实值并测试可访问
