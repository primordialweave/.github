# Primordial Weave｜品牌资产权属与许可策略

> **S0 草案 · 2026-10-25。** 本文件是组织政策建议，尚未被品牌权属人正式批准；不是法律意见，也不是授权证明。

## 1. 明确区分的权利对象

| 资产类型 | 当前判断 | 默认对外策略 | 发布前动作 |
| --- | --- | --- | --- |
| 品牌名称、字标、正式 Logo 与印章 | 品牌专用识别元素；需要核查原创性与权属 | **不自动随代码开放授权**；品牌使用另设规则 | 定稿商标/标识政策，保留可追溯源文件 |
| GitHub Banner、OG、插画 | 当前为 AI 辅助生成的视觉探索/派生版本；商用条件及排他性未逐项核实 | 不单独承诺公共领域或可自由复用 | 记录生成来源、重绘和人工确认；去除可能误认的字形 |
| 代码与应用 | 尚未统一许可证 | **每个仓库单独选择**合适的开源许可证（如 MIT 或 Apache-2.0，须由维护者批准） | 许可证文件、第三方依赖许可证检查 |
| 技术文档、翻译与设计规范 | 用户委托产生的文档与品牌内容 | 具体 CC 许可或保留权利需另行决定 | 确定 LICENSE-DOCS 或版权声明 |
| 字体 | 使用排版样式不代表拥有字体再分发权 | 不上传/分发字体文件 | 核查字体商用及嵌入授权，必要时将字标转路径 |
| 中国文化传统图形（太极、山水、云纹） | 公共文化母题，不排他 | 不宣称拥有传统文化符号本身的独占权 | 以独创组合、重绘路径与品牌应用区分 |
| 小篆「織」字印章 | AI 篆意图尚未经文字学核验 | 暂仅作为视觉参考 | 核查字形、由设计师重绘并保存可编辑母版 |

## 2. 建议的许可边界

1. **代码许可单独声明**：项目 LICENSE 只覆盖其注明的代码/其他文件；不要默认为商标 Logo 的使用许可。
2. **品牌使用规则单独声明**：未经授权不要冒充官方、误导性背书或修改为高度混淆的组织身份；正常事实性提及品牌与项目可遵守未来发布的商标使用指南。
3. **图片来源透明**：图片源为本次对话中 AI 辅助生成的视觉稿、编辑整理及导出，生成过程资料可追溯；它们目前不应被称为经律师确认的独占商标作品。
4. **公开发布前审核**：检查生成图是否有混淆字符、排版错误、他人商标或受限字体；需确认品牌持有人及实际生成工具的服务条款。
5. **引用第三方资料**：必须另行核对许可证、署名要求与再分发权限；参考古籍、图片和字体各有不同规则。

- [ ] 判断是否采用 `TRADEMARKS.md` / `BRAND_USE.md`
- [ ] 每个源码仓库由负责人选择其正式 `LICENSE`
- [ ] 若需开放品牌文档，单独确定文档类许可证与例外
- [ ] 确认本组织对外使用的司法辖区、商标风险与注册策略

## 4. 内部保存原则

- 公开仓库保存非敏感素材文件、出处、许可证、审核结论和设计规范。
- **不要**在公开的 `brand` 仓库提交账号恢复码、密码、邮箱恢复详情、持有人身份证明、付款信息或访问令牌。
- 公告、徽章、示例中的 `<ORG_HANDLE>` 在账号最终核定前保留占位符。
