# Primordial Weave Governance — Initial Baseline

This is a lightweight working agreement, not a claim of legal entity status or guaranteed response times.

**Organization owners** manage identity, access and organization-wide security. **Project maintainers** define technical direction, triage contributions, review and release. **Contributors** propose code, documentation, designs and research. Each active project must name its actual maintainers separately.

Small changes follow normal review. Large features, breaking changes, licenses, architecture and core branding require discussion before implementation. Maintainers document decisions when practical; security matters may need private discussion.

Use least-privilege repository access, enable two-factor authentication, avoid committing secrets and review permissions periodically. Document each project's lifecycle status (experimental / active / maintenance / archived), release process and licensing. The organization's logo, calligraphic seal and art assets are not automatically covered by project code licenses.
