# Support

- For bugs and feature requests, use the relevant project's issue templates; search existing reports first.
- For documentation changes, submit an issue or PR in the project repository.
- For general orientation, browse the [organization's public repositories](https://github.com/orgs/primordialweave/repositories).
- For security concerns, follow [SECURITY.md](SECURITY.md); do not post exploits publicly.

Not every repository is a released or actively supported application. Read its README and releases before expecting installation instructions or support. Never share passwords or personal details in public issues.
