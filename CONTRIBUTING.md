# Contributing to Primordial Weave

Thank you for helping build thoughtful open-source software. These are organization-wide defaults; project-specific instructions take precedence.

## Getting started
1. Read the target repository README and roadmap. Search existing issues and PRs before proposing changes.
2. Discuss significant features, breaking changes, licenses or architectural decisions in an issue before implementation.
3. Follow the repository's build, formatting, tests, accessibility and localization guidance.
4. Keep changes focused and document user-visible effects.

## Pull requests
Describe the motivation, changes, relevant issues, testing steps, compatibility impact, and screenshots when visual behavior changes. If a test cannot be run, explain why. Never share secrets, keys or private user data in code, logs or screenshots.

We welcome contributions in English or Chinese. Cultural and historical claims should be grounded in checkable references; do not represent AI-generated seal script as an authenticated historical glyph.

## Rights and licensing
Contributors must have permission to submit code and assets. The target project's own LICENSE governs its code **when a license is present**. Project code licensing does not automatically grant rights to Primordial Weave logos, seals, fonts or illustrations. If no license is set, ask maintainers before relying on reuse rights.

Read our [Code of Conduct](CODE_OF_CONDUCT.md) and [Security Policy](SECURITY.md).
