# S3 | Shared Community Standards

The public [Primordial Weave .github repository](https://github.com/primordialweave/.github) hosts organization-level contribution, conduct, security and support policies plus default issue and pull request templates.

GitHub applies these shared files to organization repositories **only when the target repo does not define its own overrides**. Project-local issue template directories override the default collection.

The [project-template repository](https://github.com/primordialweave/project-template) provides bilingual starter documentation, issue/PR templates and minimal dependency-free CI. **Mark that repo as a template manually in Settings → General** after creation.

A LICENSE is intentionally **not** provided as an organization-wide default: choose one separately for each released project. Also configure branch protection, required checks, access controls, private vulnerability reporting and language-specific CI on a per-repository basis. No automatic deployment or release is implied.

## Acceptance checklist
- [x] Shared organization community files and issue/PR templates are committed.
- [ ] Verify default issue and PR forms in the GitHub UI.
- [ ] Enable the project-template repository's template setting.
- [ ] Run project-template CI and create a sample repository.
- [ ] Select actual code licenses before releasing each project.
- [ ] Review branch rules, dependencies, security alerts and team permissions.
